PROJECT OVERVIEW
================

Tova e proekt za:
1. PyGame motorcycle dashboard
2. YOLO traffic sign detection ot kamera
3. Shared state, koito svurzva dashboard-a i sign detection-a


START POINT
===========

File:
dashboard/main.py

Tozi fail e glavniyat entry point.
Kogato puskash:

  .\.venv\Scripts\python.exe dashboard\main.py

toito:
- startira PyGame prozoreca
- suzdava central state obekt
- startira YOLO camera worker v background thread
- chaka klaviatura i window eventi
- refresh-va dashboard-a vseki frame

Main flow v dashboard/main.py:
- build_parser() -> chete argumenti kato --camera, --model, --conf, --no-camera
- handle_keydown() -> upravlqva klaviatura
- main() -> startira cqlata aplikaciq


KAK TE4E PROGRAMATA
===================

1. dashboard/main.py pravi DashboardState
2. dashboard/main.py pravi DashboardUI
3. dashboard/main.py po jelanie startira SignDetectorWorker
4. YOLO worker chete kamera i ako vidi znak, zapisva go v state
5. DashboardUI chete snapshot ot state i go risuva v PyGame
6. Klaviatura promenq speed, rpm, blinkeri, warning, blindspot i manual signs


CONFIG
======

File:
dashboard/config.py

Tuk sa vsichki osnovni nastroiki:
- razmer na prozoreca
- cvetove
- FPS
- gear ratios i drivetrain konstanti
- YOLO model path
- camera indices
- confidence threshold

Naj-vajni nastroiki:
- SCREEN_WIDTH / SCREEN_HEIGHT -> razmer na dashboard prozoreca
- FPS -> kolko burzo se refresh-va
- DEFAULT_MODEL_PATH -> koi YOLO model se polzva
- CAMERA_INDEX_CANDIDATES -> koi kameri se probvat
- YOLO_CONFIDENCE -> minimalna confidence granica


CENTRAL STATE
=============

File:
dashboard/core/state.py

Tova e shared pametta na programata.

DashboardState durji:
- speed_kmh
- rpm
- gear
- blink_left / blink_right
- warning
- blind_left / blind_right
- detected_sign
- detected_sign_confidence
- camera_status
- camera_online
- camera_index
- trip_km
- odo_km

Vajni metodi:
- snapshot() -> vrushta safe copy za UI
- set_detected_sign() -> zapisva razpoznatiya znak
- set_camera_status() -> zapisva status na kamerata/YOLO

Tuk ima lock, zashtoto state se polzva ednovremenno ot main loop-a i ot YOLO thread-a.

YOLO SIGN DETECTION
===================

File:
dashboard/core/sign_detection.py

Tova e background worker-ut za kamera i YOLO.

Kakvo pravi:
- zarejda modela
- otvarq kamera
- chete frame-ove
- puska YOLO predict
- vzema nai-silnata detekciq
- normalizira label-a do 20/30/40/50/60/70/80/HUMP/STOP
- zapisva rezultata v state

Osnovni elementi:
- SignDetectionConfig -> konfiguraciq za model, camera, conf, imgsz
- SignDetectorWorker -> thread koito vurvi paralelno na dashboard-a
- _normalize_sign_label() -> opravq imenata na klasovete
- _pick_best_detection() -> vzema nai-dobriya rezultat
- _open_camera() -> probva camera index-i

Ako iskash da promenish modela, pipni:
- dashboard/config.py
ili pusni:
  .\.venv\Scripts\python.exe dashboard\main.py --model path\to\weights.pt

KONTROLI
========

Ot keyboard:
- Up / Down -> rpm
- Left / Right -> speed
- A -> left blinker
- D -> right blinker
- W -> warning
- Q -> left blindspot
- E -> right blindspot
- 1..7 -> manual speed signs
- 8 -> HUMP
- 9 -> STOP
- 0 -> SCAN
- Esc -> exit

Manual signs sa polezni ako iskash da testvash UI bez kamera.


KAK DA GO PUSKASH
=================

Normalno:
  .\.venv\Scripts\python.exe dashboard\main.py

Bez kamera:
  .\.venv\Scripts\python.exe dashboard\main.py --no-camera

S konkretna kamera:
  .\.venv\Scripts\python.exe dashboard\main.py --camera 1

S drug model:
  .\.venv\Scripts\python.exe dashboard\main.py --model runs\detect\train3\weights\best.pt


AKO NESHTO NE RABOTI
====================

1. Ako kamera ne trugva:
- probvai --camera 1
- probvai --camera 2
- zatvori drugi programi koito polzvat kamerata

2. Ako znakut ne se pokazva:
- proveri dali model path e pravilen
- proveri dali znakut e dosta yasen pred kamerata
- namali YOLO_CONFIDENCE v dashboard/config.py

3. Ako dashboard trugva, no bez kamera:
- pusni s --no-camera i proveri dali UI raboti
- posle testvai kamerata otdelno
